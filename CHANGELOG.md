### ⚠ BREAKING CHANGES

* **places:** the place browser API addresses places by ID. GET /browse/places/{place}/persons becomes /browse/places/{id}/persons and takes a place UUID instead of place text; GET /browse/places?parent= takes a place UUID, and a text parent now answers 400; breadcrumb is a list of PlaceEntry objects instead of strings. Get a place's ID from the id of a GET /browse/places entry or from GET /places.
